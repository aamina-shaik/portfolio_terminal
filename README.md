# 💻 Portfolio Terminal

A modern terminal-inspired personal portfolio showcasing my projects, technical skills, education, certifications, and contact information through an interactive command-line interface.



## ✨ Features

- 🖥️ Interactive terminal with custom commands
- 📱 Fully responsive design
- 🎨 Modern terminal-inspired UI
- 👩‍💻 About Me section
- 🛠️ Technical skills showcase
- 📂 Featured projects
- 🎓 Education timeline
- 🏆 Certifications & achievements
- 📬 Contact section with quick links
- 🖱️ Draggable terminal window
- 📄 Resume download shortcut

## 💻 Terminal Commands

| Command | Description |
|----------|-------------|
| `help` | View all available commands |
| `about` | About me |
| `skills` | Technical skills |
| `projects` | Featured projects |
| `education` | Academic details |
| `contact` | Contact information |
| `resume` | Open resume |
| `status` | Current status |
| `date` | Display current date |
| `joke` | Random programming joke |
| `motivate` | Motivational message |
| `coffee` | Coffee command ☕ |
| `clear` | Clear terminal |
| `exit` | Exit message |

## 🚀 Run Locally

```bash
git clone https://github.com/aamina-shaik/portfolio_terminal.git

cd portfolio_terminal

open index.html
```

Or use a local server:

```bash
python -m http.server
```

Then visit:

```
http://localhost:8000
```
